# Ручное тестирование мобильного приложения «ЯМетро»

Полный цикл ручного тестирования новой функциональности мобильного приложения метро (Android) — от декомпозиции требований до решения по релизу.

## Контекст

- **Объект**: мобильное приложение «ЯМетро» (схема метро, построение маршрутов, карточки станций и маршрутов, настройки).
- **Задача**: протестировать новую функциональность (построение маршрута, история маршрутов, карточки, лонг-тап) и провести регрессионный прогон особенностей приложения перед релизом.
- **Окружение**: Android 9.0 Pie, эмулятор Honor 8, 1080×1920.
- **Роль**: единственный тестировщик, полный цикл.

## Ключевые находки

- **Кластер дефектов по смене ориентации**: 5 из 18 тестов блока упали — карточки меняют положение при повороте (Б4, Б12, Б13) и слетает масштаб маршрута (Б14, Б15). Плюс деградация производительности при повороте (Б9, найден регрессом).
- **Два бага заблокировали прогресс**: Б7 (приложение не реагирует на потерю сети) заблокировал проверку восстановления соединения, Б8 (кнопка обратной связи открывает почтовый клиент вместо Webview) — проверку перехода. Прогон помечен как Blocked, а не как «дефектов не найдено».
- **Граничные значения истории маршрутов**: нарушены оба лимита — сортировка при 2 станциях и лимит в 3 (Б1, Б2).
- **Пробел в покрытии, найденный через трассировку**: смена темы тёмная→светлая в 6:00 МСК (другой часовой пояс) не покрыта тестом — требование есть, теста нет. Зафиксировано как задача до релиза.

## Решения по релизу

- **Высокий риск**: блок «Смена ориентации» — формальных блокеров не найдено, но кластер средних дефектов (масштаб + производительность) требует фикса до релиза.
- **Высокий риск**: блок «Сеть / офлайн» — прогон заблокирован багами Б7/Б8, часть сценариев не проверена (не «не найдено», а «не проверено»).
- **Средний риск**: история маршрутов (Б1–Б3), тема (Б10 — нужен тест на 6:00 МСК), обновление (Б11).
- **Средний риск**: жесты и геолокация — три теста Skipped (пинч, спред, NFC),
  запланирован прогон на реальном устройстве.

## Что можно улучшить

- Прогон на физическом устройстве с первого дня: жесты и NFC не должны выпадать из покрытия из-за ограничений эмулятора.
- Тест на 6:00 МСК планировала бы сразу в регресс, а не находила бы через трассировку после прогона.
